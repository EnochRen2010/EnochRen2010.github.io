# Personal portfolio

A lightweight, responsive portfolio site built with plain HTML, CSS, and JavaScript.

## Make it yours

Edit `index.html` to update the name, introduction, project titles and descriptions, interests, and contact link. Replace `hello@example.com` with an email address you are comfortable making public, or remove the contact button. The artwork is built from CSS, so no image assets are needed.

## Deploy

The included GitHub Actions workflow deploys the site to GitHub Pages whenever you push to `main`. In the repository, check **Settings → Pages** and choose **GitHub Actions** as the build and deployment source if it is not already selected. The published address for a user site is `https://enochren2010.github.io/`.
